Parenthink Support

Help for iPhone and iPad · Updated August 2, 2026

EnglishBahasa Indonesiaภาษาไทย

English

Parenthink 1.0 supports compatible iPhone and iPad devices running iOS/iPadOS 26 or later.

Quick troubleshooting

  1. Update Parenthink and iOS/iPadOS, then restart the app.
  2. Confirm the device has available storage and a working network connection.
  3. For reminders, check both Parenthink → Settings → Notifications and iOS Settings → Notifications → Parenthink. Past reminders are never scheduled.
  4. For purchases, open the Premium tab and use Restore purchases with the Apple Account that purchased the subscription.

iCloud Family Sync

  • Confirm iCloud Drive is enabled and Parenthink is allowed to use iCloud.
  • A Premium owner enables Family Sync under Home → Settings → Family sync. Invited collaborators can edit an accepted shared workspace without Premium.
  • Accept invitations from Apple’s system invitation. Parenthink protects an invitee’s previous local family in a device-only backup before replacing the active cache.
  • When offline, keep the app installed and reconnect later. Pending local changes remain queued.

Data recovery

If Parenthink cannot open its local database, do not delete the app. Use Retry, free device storage, and restart. Use Create protected backup before reinstalling or deleting anything. Deleting the app can remove local-only records.

Contact

For app support, create a GitHub issue without child, medical, school, Apple user ID, receipt, or other private information. Apple handles billing and eligible refund requests.

Bahasa Indonesia

Parenthink 1.0 mendukung iPhone dan iPad yang kompatibel dengan iOS/iPadOS 26 atau lebih baru.

Pemecahan masalah cepat

  1. Perbarui Parenthink dan iOS/iPadOS, lalu mulai ulang aplikasi.
  2. Pastikan ruang penyimpanan cukup dan jaringan berfungsi.
  3. Untuk pengingat, periksa Parenthink → Pengaturan → Notifikasi dan Pengaturan iOS → Notifikasi → Parenthink. Pengingat yang sudah lewat tidak dijadwalkan.
  4. Untuk pembelian, buka tab Premium dan gunakan Pulihkan pembelian dengan Akun Apple yang melakukan pembelian.

Sinkronisasi Keluarga iCloud

  • Pastikan iCloud Drive aktif dan Parenthink diizinkan memakai iCloud.
  • Pemilik Premium mengaktifkan Sinkronisasi Keluarga melalui Beranda → Pengaturan → Sinkronisasi keluarga. Kolaborator undangan dapat mengedit ruang yang diterima tanpa Premium.
  • Terima undangan dari sistem Apple. Sebelum mengganti cache aktif, Parenthink melindungi keluarga lokal sebelumnya dalam cadangan khusus perangkat.
  • Saat offline, jangan hapus aplikasi dan sambungkan kembali nanti. Perubahan lokal tetap mengantre.

Pemulihan data

Jika Parenthink tidak dapat membuka basis data lokal, jangan hapus aplikasi. Gunakan Coba lagi, kosongkan penyimpanan, dan mulai ulang. Gunakan Buat cadangan terlindungi sebelum memasang ulang atau menghapus apa pun. Menghapus aplikasi dapat menghilangkan catatan yang hanya ada di perangkat.

Kontak

Untuk dukungan, buat isu GitHub tanpa data anak, kesehatan, sekolah, ID pengguna Apple, tanda terima, atau informasi pribadi lain. Apple menangani penagihan dan permintaan pengembalian dana yang memenuhi syarat.

ภาษาไทย

Parenthink 1.0 รองรับ iPhone และ iPad ที่เข้ากันได้ซึ่งใช้ iOS/iPadOS 26 ขึ้นไป

แก้ปัญหาเบื้องต้น

  1. อัปเดต Parenthink และ iOS/iPadOS แล้วเปิดแอปใหม่
  2. ตรวจว่ามีพื้นที่เก็บข้อมูลและเครือข่ายทำงาน
  3. สำหรับการเตือน ตรวจทั้ง Parenthink → การตั้งค่า → การแจ้งเตือน และ การตั้งค่า iOS → การแจ้งเตือน → Parenthink แอปจะไม่ตั้งการเตือนในอดีต
  4. สำหรับการซื้อ เปิดแท็บ Premium และใช้ กู้คืนการซื้อ ด้วยบัญชี Apple ที่ซื้อการสมัคร

การซิงค์ครอบครัว iCloud

  • ตรวจว่าเปิด iCloud Drive และอนุญาตให้ Parenthink ใช้ iCloud
  • เจ้าของ Premium เปิดซิงค์ที่ หน้าแรก → การตั้งค่า → ซิงค์ครอบครัว ผู้ร่วมงานที่ได้รับเชิญแก้ไขพื้นที่ที่รับแล้วได้โดยไม่ต้องมี Premium
  • รับคำเชิญจากระบบ Apple ก่อนแทนที่แคช แอปจะเก็บครอบครัวเดิมของผู้รับเชิญไว้ในข้อมูลสำรองเฉพาะอุปกรณ์ที่มีการป้องกัน
  • เมื่อออฟไลน์ อย่าลบแอปและเชื่อมต่อใหม่ภายหลัง การเปลี่ยนแปลงในเครื่องจะยังอยู่ในคิว

การกู้ข้อมูล

หากเปิดฐานข้อมูลไม่ได้ อย่าลบแอป ใช้ ลองอีกครั้ง เพิ่มพื้นที่ว่าง และเปิดเครื่องใหม่ ใช้ สร้างข้อมูลสำรองที่มีการป้องกัน ก่อนติดตั้งใหม่หรือลบสิ่งใด การลบแอปอาจทำให้บันทึกที่มีเฉพาะในเครื่องหายไป

ติดต่อ

สร้างประเด็น GitHub โดยห้ามใส่ข้อมูลเด็ก สุขภาพ โรงเรียน รหัสผู้ใช้ Apple ใบเสร็จ หรือข้อมูลส่วนตัวอื่น Apple ดูแลการเรียกเก็บและการคืนเงินที่เข้าเกณฑ์
